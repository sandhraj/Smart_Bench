Legend

Jumper wire — insulated wire laid on the component side, straight along a row/column. Label = hop id.
Solder bus — thick line = solder bridging up to 5 adjacent holes on the underside (solder-side view only).
Wire end — hole where a jumper is soldered.
Resistor — value printed beside it.
Diode — light band = cathode.
Ceramic cap (orange)
Electrolytic cap (navy) — mind polarity.
DIP IC — white dot = pin 1.
Header / connector (J1–J8) — pin names printed alongside.
Used pad — pin connected to a net.
NC pad — pin present but unconnected.
Module outline — ESP32 DevKit (green) or GY-45 (blue) sitting above the board.
Mounting hole
Hole name — column letter A–AL (left→right) + row 1–23 (top→bottom), as in wiring.md.
